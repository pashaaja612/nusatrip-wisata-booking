
# NusaTrip - Aplikasi Pemesanan Paket Wisata

NusaTrip merupakan aplikasi berbasis web untuk melakukan pemesanan paket wisata. Project ini dibuat sebagai tugas individu mata kuliah Pemrograman Aplikasi Internet 2.

## Teknologi yang Digunakan
- PHP
- MySQL
- HTML
- CSS

## Fitur Aplikasi
- Form pemesanan paket wisata.
- Pilihan kategori wisata.
- Validasi data pemesan.
- Penyimpanan data pemesanan ke database.
- Menampilkan data pemesanan.

## Struktur File
- `index.php` - Halaman utama dan form pemesanan.
- `koneksi.php` - Koneksi database.
- `simpan.php` - Proses penyimpanan pemesanan.
- `tampil.php` - Menampilkan data pemesanan.
- `style.css` - Pengaturan tampilan aplikasi.

## Cara Menjalankan
1. Install XAMPP atau Laragon.
2. Letakkan folder project di direktori web server.
3. Jalankan Apache dan MySQL.
4. Buat database sesuai konfigurasi pada `koneksi.php`.
5. Sesuaikan konfigurasi koneksi database.
6. Buka aplikasi melalui browser menggunakan localhost.
